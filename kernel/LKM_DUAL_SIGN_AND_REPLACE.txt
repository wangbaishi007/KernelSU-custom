Dual Manager signing (LKM / kernelsu.ko)
=======================================

1) Compute KSU_EXPECTED_SIZE2 / KSU_EXPECTED_HASH2 from YOUR signed Manager APK (v2-only; no v3-only):
   cd userspace/ksud
   cargo run -- get-sign --kbuild /path/to/your-KernelSU-manager.apk

2) Either:
   - Create kernel/ksu-manager-signing.local.mk (copy from ksu-manager-signing.local.mk.example)
     and paste the two lines from step 1; then build; OR
   - Pass on make command line:
     CONFIG_KSU=m CC=clang make KSU_EXPECTED_SIZE2=0x.... KSU_EXPECTED_HASH2=.....

3) DDK container (same as .github/workflows/ddk-lkm.yml): in kernel/
   CONFIG_KSU=m CC=clang make
   Output: kernel/kernelsu.ko — rename to <kmi>_kernelsu.ko if you distribute per-KMI.

4) Replace .ko inside your KMI / AnyKernel3 zip:
   - Unzip the flashable package, overwrite the existing *kernelsu.ko (or module/kernelsu.ko per maintainer layout).
   - Re-zip preserving structure; flash in recovery, OR use KernelSU Manager / ksud to supply the new .ko when patching boot (if your flow embeds LKM into patched image).

5) Re-patch boot with Manager or: ksud boot-patch ... -m /path/to/new/kernelsu.ko
   Then fastboot flash boot/init_boot + vendor_boot as required for your device.

Official primary signature remains Kbuild defaults; only adds second cert when SIZE2/HASH2 set.
